# GitHub community setup

After creating `ASVLCII/Nano-Origin`:

1. Enable **Discussions** in the repository settings.
2. Create four categories: Announcements, Ideas, Q&A, and Development.
3. Pin a welcome discussion asking for help with Windows testing, Firefox ESR policy review, and packaging.
4. Enable Issues and add `good first issue`, `help wanted`, `windows`, `packaging`, `privacy`, and `documentation` labels.
5. Add the short repository description:

   > A lightweight, privacy-first community browser for Windows—Firefox ESR base, uBlock Origin, DuckDuckGo No AI, and a compact Orbit design.

Keep the first requests narrow. “Run this in Windows Sandbox and report the taskbar identity” is easier for a new contributor to pick up than “help build a browser.”
